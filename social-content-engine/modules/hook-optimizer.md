# Hook Optimizer

Use only when the user asks for an opening/hook or review returns `WEAK_HOOK`.

## Goal

Create a reason to continue without clickbait.

## Internal hook families

Generate up to three genuinely different candidates:

1. concrete observation
2. tension / contrast
3. specific fact or implication

Do not generate three cosmetic rewrites of the same sentence.

## Good hooks

A hook may offer:

- new information
- a specific claim
- a useful contradiction
- a recognizable problem
- a clear payoff

## Avoid

- vague questions
- “you won’t believe”
- fake urgency
- generic “big news”
- empty superlatives
- withholding the main point for engagement

## Multilingual

Regenerate hooks in the target language. English-style rhetorical questions often translate poorly into Chinese, Vietnamese, Japanese, or Korean. Follow local conversational rhythm.

## Output

Select one strongest hook by default. If the user explicitly asks for options, return up to three distinct options.
