# 间距与视觉分组

间距告诉人哪些元素属于同一项、从哪里开始读、下一组在哪里。导航里的图标和文字要足够靠近，让人一眼认出它们是同一个入口，也要留出清晰空隙，让图标轮廓和字形各自可辨。同级标签沿同一条起始线排列，用户就能顺着文字快速扫完一列。组与组之间加大距离，让关系和层级在没有分割线时也能读懂。

## 导航图标与文字

- **用图标槽宽度固定文字起点。** 同级菜单项共享前置图标槽、内边距和图文间距。常见 16–20px 图标可用相应的固定槽位，将较小图标居中。若同一组内混用带图标与无图标的同级项，并且希望文字起点一致，用组件的列结构保留槽位；子菜单用有意的层级缩进。徽标、快捷键和展开箭头放在独立的末端区域。
- **先用项目现有值。** 没有现成定义时，Web 可从 **8 CSS px** 图文间距起试。紧凑且图标较小时可以试 6px，较大图标或宽松导航可以试 12px。三者是 Bluue 的试排起点，实际值依据字体、可见笔画、图标自带留白、触控密度和标签长度调整。同一语义与密度下优先复用同一值。
- **用布局表达距离。** 横排用 Flex 或 Grid 的 `gap` 连接图标槽与标签；末端区域有独立的分配规则。文字变长时让标签区合理换行或按组件规则截断，保持图标尺寸和文字起点。单行可居中，多行标签按需要对齐首行。双向布局以行内起始边为基准。
- **检查视觉和点击两件事。** 间距从图标槽外框到文字盒计算，再看图标实际笔画与文字之间的可见留白。单个导航目标包含图标、文字及其内边距；同一目的地可点击整行。独立的尾部按钮单独测量点击区域，与主入口保持足够区隔。

例如，同级侧栏行用 20px 图标槽、8px 图文间距、12px 起始内边距，标签就从行的起始边向内 40px 开始。鼠标悬停或选中时仍沿这条线，避免因选中边框、图标变体或末端徽标而位移。

## 把间距落实到布局层级

| 距离 | 用途 | 设置位置 |
|---|---|---|
| 图标与文字、标题与说明 | 表明它们属于一项，保留可辨认的留白 | 组件内部的 `gap` |
| 内容与选中底色、边框或面板边缘 | 维持同组内容的公共边，提供必要的可操作面积 | 容器的 `padding` |
| 相邻导航项、列表项或表单字段 | 保持同级项的节奏，区分不同操作 | 父级列表或布局的间距 |
| 导航分组、表单章节、页面区块 | 拉开任务和章节层级 | 按分组或区块设置更明显的间隔 |

优先用现有间距 Token。新界面缺少体系时，用少量刻度即可，例如组件内 4/8/12、容器内 12/16、区块间 24/32 CSS px，可根据实际密度选用。比较的是可见内容之间的距离，行高、图标留白和内边距都会影响结果。一个距离尽量由一层布局负责，避免父级 `gap`、子项 `margin` 和占位同时累加。

交付前看默认、选中两种状态下的标签起点，并用较长标签及窄屏复核。触控区域按实际可点击范围验证。WCAG 2.2 对 Web 指针目标的 24×24 CSS px 与其例外，适用于目标大小及目标之间的关系，图标到文字的间距由组件布局决定。
