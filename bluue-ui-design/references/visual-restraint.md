# 视觉克制与反模板化偏好

来源：用户于 2026-10-29 提供的明确设计偏好。用于新设计、实质性视觉优化和 UI 风格审查；它不是行业统一标准，也不能据此识别作品的作者或生成方式。目标是让内容和操作成为主角，不用装饰模拟完成度。

## 字体与排版

- **字体选择**：新设计默认不选 Instrument Serif、Space Grotesk、Bricolage Grotesque；不能换成相似流行字体就当作完成去模板化。沿用有效品牌字体与真实资源，考虑目标语言覆盖。仅修文案或局部控件时，不擅自替换全站字体。
- **斜体与标签**：不把关键词、短句或卡片标题批量设为斜体；不把普通描述都做成胶囊标签。真实分类、状态、筛选条件和语义上必要的强调可保留，表单标签不可因减法消失。
- **等宽字体**：只用于确有用途的代码、标识符或需要逐字符比较的内容。数字列需要位数对齐时优先普通字体的等宽数字能力，不把整页标题、说明和导航都改成等宽。
- **字号数量与下限**：单页默认先定义最多四档字号 Tokens，通过字重、行高、间距建立更多层级；同一角色的响应式变化不算新增角色。默认不把应用内可见文字设计到 12 CSS px 以下，移动正文和长文使用更舒适的字号。用户缩放、系统大字体和必要的可访问性适配不受四档上限限制；复杂编辑器等确需更多层级时基于内容说明取舍，不为了凑四档抹平层级。SVG 按最终展示比例检查，不能源码写 12、整体缩放后却小于 12。
- **Hero 标题**：按首屏内容、视口和任务确定大小，确保标题、必要证据与主要操作形成合理关系；不用占满屏幕的巨字、强制断词或大量换行制造冲击。明确的海报或品牌展示需求才采用夸张尺度。
- **全大写小标题**：英文小标题默认正常大小写，不叠加全大写、过宽字距与微小字号。真实缩写、品牌拼写、代码不机械改写。

## 文案与装饰性文字

- **直接说事实和动作**：使用用户熟悉的对象名、动作、结果。避免过度聊天式语气、卖萌安慰、空泛感叹、自造名词和刻意模仿品牌发布会的夸张句式；自然易懂不等于冷硬或机械。
- **每句话提供增量信息**：不在“课表”下面再写“轻松查看你的课程安排”，不把“今日无课”扩写为鼓励性段落；必要的首次使用指引、费用、限制和错误恢复仍应保留。不要为了少字删掉用户做决定所需的信息。
- **默认不新增眉标、章节编号与代码式面包屑**：如标题上方的英文小标签、每个区块前的 01/02、伪路径和无意义技术标记。真实导航路径、多步骤流程与需要引用的章节可保留对应结构；不要用装饰编号假装信息架构。
- **中圆点分隔**：默认不新增 `·` 或 `•` 把标题、日期、状态串成固定模板；优先自然短语、分组与留白，例如“明天第 3 节”。保留专名、原文和实际语义中的符号，不做全局字符删除；这也不是禁止语义列表。
- **Emoji**：不主动塞进正文、按钮和标题当作点缀或替代产品图标；用户原始内容、消息、表情功能和明确品牌需求可保留。

## 边界、表面与颜色

- **减少重复分组信号**：留白已经说明关系时，不再为每个模块加横线、描边盒子和底色。浮层确需层次时使用项目阴影 Token，不为“精致”逐卡叠加多层阴影和半透明色块。输入、选中与焦点仍要清楚。
- **同心圆角**：均匀内缩、相似轮廓的嵌套圆角应保持共同圆心关系。可从“内圆角 = 外圆角减对应轮廓间距，最低为零”理解，再结合边框和实际表面边界调整；非均匀内边距、不同轮廓不能机械套一个减法。不要所有嵌套层都用同一圆角值。
- **线宽一致**：建立按角色区分的线宽 Tokens；同层分割线、同族图标和同类控件一致。轻分隔在目标渲染允许时考虑 0.5px hairline，而不是处处 1px；实际检查设备像素比和缩放后的清晰度。不要求所有角色用同一线宽，也不把关键边界、选中或焦点变细到不可见。
- **紫色渐变**：默认不采用；没有品牌依据时不把紫色光晕、彩色渐变和玻璃叠层作为视觉方案的起点。用户明确指定的品牌或复刻要求优先。
- **卡片左侧彩色竖线**：默认不生成装饰性竖线，尤其避免“竖线 + 底色 + 描边 + 徽章”重复强调。确实承担时间线、引用或状态语义时，保留有意义的编码并提供非颜色线索。
- **下拉箭头**：普通按钮不附加无功能的 chevron；菜单、选择器和分裂按钮只保留识别行为所需的一处提示，不重复叠加箭头和“点击展开”文案。不能为了干净把真实下拉控件伪装成无提示的普通文本；优先已有成熟组件的清晰交互。

## 图表与动效

- **图表细节有选择**：先确定用户要比较、定位异常还是读取精确数值；再决定系列、刻度、网格线、图例、标注与 Tooltip。避免默认每点标值、满格网格线、重复图例和多层说明。保留必要单位、时间范围、数据口径和影响判断的异常，精确数据提供可访问的查看方式，不能把一切藏到 hover。
- **滚动保持平稳**：默认正文和列表直接呈现，不逐段重复淡入、弹跳、视差或滚动绑定缩放，不劫持原生滚动。按功能需要保留少量自然、可中断的过渡，及时收敛到稳定状态；遵循主 Skill 的减弱动态设置和中断规则，不新增固定时长体系。

## 应用与复核

先移除没有信息价值的元素，再修排版、对齐和组件关系，不以换一种装饰替代原有装饰。局部任务只修改授权区域；不要为了满足清单清空真实内容、删除必要交互线索或重写全站品牌。

交付前对受影响区域做一次有针对性的检查：字体与字号是否收敛，是否有重复解释、装饰标记和边界，图表与动效是否超出任务所需。此表不是强制添加的 UI 文案，也不要求新建评分器、截图矩阵或饱和式测试。
